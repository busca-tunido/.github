# BuscaTuNido

A collaborative web platform designed for out-of-town university students to search, compare, and validate student housing (pensiones) with transparent pricing, verified rules, and community contributions.

## Repositories

- [**web**](https://github.com/busca-tunido/web): Next.js mobile-first frontend built with Tailwind CSS and shadcn/ui.
- [**api**](https://github.com/busca-tunido/api): NestJS modular backend service with Prisma ORM and PostgreSQL.

## Architecture & Workflow

- **Mobile-First UX**: Responsive interface optimized for mobile and desktop viewports.
- **Contract-Driven**: Type-safe communication powered by OpenAPI specifications.
- **Task Lifecycle**: All changes tracked through repository-specific task tickets in `tasks/`.
